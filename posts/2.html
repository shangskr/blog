RDPWrap破解Windows多用户远程桌面

发表于2023-01-07|更新于2023-01-07|教程
|浏览量:

RDPWrap 是什么

GitHub 上面介绍很详细，地址：

  • (1) https://github.com/loyejaotdiqr47123/rdpwrap （长期更新）”rdpwrap.exe”的版本更高。
  • (2) https://github.com/stascorp/rdpwrap (未知更新)”rdpwrap.exe”的版本较低

所有使用的工具下载地址

  • 工具包下载：https://yuwushang.lanzouf.com/b041nfpqf
  • 密码：1234（请自行选择版本，提倡使用最高版本）

注： 如果打不开，请把链接中的 lanzouf 中的 f 更改为 x 或者 i 等等就可以打开了

安装 RDPWrap-v1.6.2

解压安装包后以管理员身份运行 install.bat（用来安装配置）

启动以后等待出来红色方框里面的内容按任意键退出

启动 RDPConf.exe（此文件用来检测上一步是否安装成功）

打开以后方框内的红色文字一致就说明安装完成（下面勾选的要和图片一致）

当微软更新补丁以后，都需要检测一下是否破解有效。如果解锁无效，需要以管理员身份运行下图的 update 程序，然后再检测是否有效

下图的 uninstall 命令是用来解除 Windows 多开功能，恢复原始状态（需要以管理员身份运行）

当满足下图方框内的文字时就说明破解成功了，就可以多开 Windows 连接了

启动 RDPConf.exe 后可能会遇到 “not supported”

这是配置的问题，需要解决。

运行安装 install.bat 会在 C:\Program Files\RDP Wrapper 下面生成 2 个文件：rdpwrap.dll，rdpwrap.ini（配置文件）

10.0.17763.1 是系统版本，是需要编写成系统匹配的版本时，这个配置文件才会加载系统 termsrv.dll

查看系统版本号

Windows+R 输入 winver，如果系统版本在配置文件中没有就需要手动编写或直接在 GitHub 上复制其他人的系统配置文件

rdpwrap.ini 配置文件写入生成

手动配置

在 GitHub issues 上面查找到与自己系统匹配的版本，复制配置文件脚本到自己的 rdpwrap.ini 文件中

地址：https://github.com/stascorp/rdpwrap/issues

找到支持的就可以

注意： rdpwrap.ini 配置文件修改后需要重新启动服务才能生效

  • 停止服务：net stop termservice
  • 启动服务：net start termservice

Windows+R 输入 cmd，打开以后重新启动服务：如图

然后 “not supported” 的问题就解决了

使用 rdpwup 自动生成

启动 rdpwup.exe，等待工具自动扫描，然后点击 update，会自动在 C:\Program Files\RDP Wrapper\rdpwrap.ini 文件中自动生成配置信息

自动生成配置信息

重启服务，启动 RDPConf.exe

以上两种方法用来解决 “not supported”

当运行 RDPConf.exe 看到的是 “fully supported”，就破解成功了。可以实现多用户登入一台电脑。

提示： 多用户登入一台电脑，如果需要限制硬盘（文件）的使用权限请另外对用户进行设置！
